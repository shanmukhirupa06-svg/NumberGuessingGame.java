ATM Interface Using Java

Project Description

The ATM Interface is a simple Java console-based application that simulates basic ATM operations.

Features

1. Check Account Balance
2. Deposit Money
3. Withdraw Money
4. Exit the Application

Technologies Used

- Java
- Scanner Class
- Switch Statement
- If-Else Statement
- Do-While Loop

Initial Balance

Rs. 5000

How to Run

1. Open the Java compiler.
2. Copy the ATMInterface.java code.
3. Run the program.
4. Select an option from the ATM menu.

Output

The program displays the account balance, deposit confirmation, withdrawal confirmation and exit message.

Conclusion

This project demonstrates basic Java programming concepts through a simple ATM simulation.
