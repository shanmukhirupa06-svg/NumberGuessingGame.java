ATM Interface

Project Description

The ATM Interface is a Java-based console application that simulates basic ATM banking operations. It allows users to log in securely and perform different banking activities through a menu-driven program.

Technologies Used

- Java
- Scanner Class
- ArrayList
- Variables and Data Types
- If-Else Statements
- Switch Statement
- Do-While Loop
- For Loop
- Methods
- Exception Handling

Features

1. User Login and PIN Verification
2. Check Account Balance
3. Deposit Money
4. Withdraw Money
5. Transfer Money
6. View Transaction History
7. Change PIN
8. Exit the Application

Default Login Details

- User ID: user123
- PIN: 1234
- Initial Balance: Rs. 5000

How to Run

1. Open the Java project.
2. Compile the ATMInterface.java file.
3. Run the program.
4. Enter the User ID and PIN.
5. Select an operation from the ATM menu.
6. Follow the instructions displayed on the screen.
