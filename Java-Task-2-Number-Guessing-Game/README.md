# Number Guessing Game

## Project Description
This is a Java-based number guessing game.

The computer generates a random number between 1 and 100.
The user has 7 attempts to guess the correct number.

The game gives hints:
- Too High
- Too Low
- Correct

## Technologies Used
- Java
- Random Class
- Scanner Class
- While Loop
- If-Else Statements
- Variables
- Conditional Statements
- Basic Java Programming Concepts

## Conclusion
This project demonstrates basic Java programming concepts.
